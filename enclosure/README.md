These files can be used to 3D print an enclosure to hold the solar panel and battery for the data logger.

Note that the models assume all measurements are in millimeters.

You can use [These screws from Hobby Lobby](https://www.hobbylobby.com/crafts-hobbies/wood-crafts-blank-surfaces/accessories-hardware-tools/brass-plated-mini-screws---8mm/p/23929) to connect the parts.
